# Gamma.app pitch deck prompts

Use these files to regenerate Persistent **Semicolons 2026** pitch decks in [Gamma.app](https://gamma.app) with matching layout and colors.

| File | Slides | Use when |
|------|--------|----------|
| [`gamma-brand-guidelines.md`](gamma-brand-guidelines.md) | — | Set theme / colors first |
| [`gamma-prompt-10min-standard.md`](gamma-prompt-10min-standard.md) | 7 | 10-minute judging format |
| [`gamma-prompt-detailed.md`](gamma-prompt-detailed.md) | 11 | Full solution pitch |

## Quick steps

1. Open Gamma → **Create with AI** → paste prompt from chosen file (entire code block).  
2. Apply brand colors from `gamma-brand-guidelines.md`.  
3. Replace screenshot placeholders on demo/Allure slides with real captures.  
4. Export PDF/PPTX for submission.
